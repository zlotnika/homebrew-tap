# homebrew-tap

```sh
brew install zlotnika/tap/yorick
```

| Cask                        | What it is                                                   |
| --------------------------- | ------------------------------------------------------------ |
| [`yorick`](Casks/yorick.rb) | [Yorick](https://heyyorick.com/) — local dictation for macOS |

Uninstall: `brew uninstall --cask yorick` (add `--zap` to also remove settings and downloaded models).
